# Notebook Server

独立的自托管 Markdown 网页笔记服务，面向电脑和手机浏览器。一个 Node.js 进程提供 REST API、静态网页和服务端文件存储；运行时无第三方依赖。

此项目不等同于 Electron / Android 客户端，也没有实现它们的 WebDAV 日志同步协议。笔记库保存在服务器，浏览器缓存尚未保存的编辑草稿；不支持断网首次启动或完整离线浏览整个笔记库。

## 启动

需要 Node.js 22.12+（22 LTS 系列）或 24+。

```sh
cd sub
node server/server.js
```

访问 `http://127.0.0.1:8080`。默认监听 `0.0.0.0`，同一局域网可用服务器地址访问。可以在设置中启用服务器登录密码；公网使用时由反向代理提供 HTTPS。

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| PORT | 8080 | 端口 |
| HOST | 0.0.0.0 | 监听地址；仅本机使用可设为 127.0.0.1 |
| DATA_DIR | sub/data | 独立数据目录 |

## 编辑与保存

支持笔记本、分区、页面树、标签、收藏、任务、步骤、评论、附件、搜索、Wiki 链接、反向链接、知识图谱、版本历史、回收站和阅读位置。

Markdown 支持常用 GFM 语法、代码高亮、表格、任务列表和 Wiki 链接。公式标记保留源文本，目前没有 TeX 排版引擎。电脑可分屏编辑/预览；手机采用单栏，导航和信息面板按需打开。文档的任务属性默认收起。

保存按页面排队，并在切页时立即提交待保存快照。慢请求完成后如果还有更新，会继续保存最新快照。标题、正文和元数据同时写入本机草稿；成功确认的快照才会清除。断网后保留草稿，网络恢复时重试；刷新后可选择恢复、下载或丢弃草稿。

页面保存使用 `expectedUpdatedAt` 检查服务器版本。另一台设备修改过同一页面时返回 409，停止自动覆盖并保留本机草稿。界面可以下载草稿、保留待处理，或明确丢弃本机修改并载入服务器版本。没有自动合并功能。旧 API 调用方省略版本字段时仍按旧语义保存。

本机草稿存于当前浏览器的 localStorage，未加密；清理浏览器数据会移除这些草稿。它们不是服务器备份。浏览器存储空间不足时会显示提示，仍尝试服务器保存。

快捷键：Ctrl/Cmd+S 保存，Ctrl/Cmd+B/I 加粗/斜体，`/` 在非输入区域聚焦搜索，Esc 关闭弹层，Tab 在编辑器缩进。

## 导出、备份与恢复

- **导出 Markdown**：单页 `.md` 或全部正文 `.zip`，用于文本交换；不包含附件二进制、历史和完整关系。
- **完整备份**：设置 → 下载完整备份。包含工作区、笔记本/隐私锁配置、分区、页面正文与元数据、标签、任务步骤、评论、阅读位置、附件和版本历史。必须先解锁全部私密笔记本。
- **恢复完整备份**：设置 → 恢复完整备份，仅允许全新的空工作区。创建过笔记本/标签或有回收站数据也不算空；建议以新的 DATA_DIR 启动实例后恢复。不会合并或覆盖已有工作区。

备份 ZIP 未加密，应妥善保存。服务器登录密码、登录会话、解锁会话和服务器名称等部署设置不随备份恢复；恢复后私密笔记本仍需原笔记本密码解锁。此备份格式属于本网页服务，不能直接当作原生客户端的备份。

Markdown 导入支持 `.md` 及普通 ZIP 的 STORE/DEFLATE 压缩、UTF-8 文件名和数据描述符。ZIP64、加密 ZIP 和其他压缩算法不支持。上传上限 256 MiB，解压累计上限 512 MiB；备份在内存中构建，大库应同时保留停服后的数据目录备份。

## 诊断日志

设置中可分别导出浏览器诊断和服务器诊断。报告问题时提供大致发生时间、执行了什么操作、看到的错误，再附这两份日志即可。浏览器与服务器共享 operationId，可关联保存失败、版本冲突和慢请求。

服务器日志位于 `DATA_DIR/diagnostics/events.jsonl`，单文件 512 KiB，最多 4 个文件（2 MiB）；浏览器保留最多 200 条且不超过 256 KiB。记录会轮转淘汰旧事件，不按固定天数保留。启动、变更请求、失败和超过 1 秒的读取会记录；普通轮询读取和逐字输入不记录。重复错误在 30 秒内压缩为计数，突发队列最多 128 项。日志不可写不会阻断笔记操作。

记录仅含时间、版本/会话、操作编号、路由模板、页面哈希引用、状态、耗时和错误类型/源码行号；不包含正文、标题、上传文件内容、搜索词、URL 查询、密码、Cookie 或异常原文。日志默认只在本机，不上传遥测。服务器诊断导出沿用服务器登录权限。浏览器日志在清理站点数据后会消失；完全断网仍可在已打开的设置中导出本机日志。

## 提醒与隐私

每日、每周、每月提醒由服务器计算当前发生时间，不修改笔记的保存版本。每月保留原始 UTC 日和时间，短月份取月末；每日/每周为固定时间间隔。完成的任务不再提醒。

网页打开时每分钟检查提醒，并对同一发生时间去重。设置中可主动授予系统通知权限；不支持该接口的手机浏览器使用页内提醒。没有 Service Worker 推送：网页关闭、浏览器被系统挂起时不能保证通知，夏令时地区也不会自动按本地墙上时间调整固定间隔。

笔记本隐私锁控制 API 访问，不是磁盘加密。改密、移动目标、附件、版本与关联操作均检查解锁权限；可以同时解锁多个笔记本。附件无有效页面关联时拒绝读取，响应不进入公共缓存。服务端磁盘上的正文和备份仍可由系统账户读取。

## 存储与故障行为

```text
data/
  index.json            工作区和全部关系索引
  meta.json             服务器设置和登录密码哈希
  pages/<id>.md         Markdown 正文
  revisions/<pageId>/   历史正文与元数据
  assets/<sha256>       附件二进制及同名 .json 元数据
```

正文、索引、元数据、版本与附件采用临时文件、fsync 和重命名写入。写操作返回成功前会等待持久化；损坏索引会拒绝启动并报错，避免被误当成空库覆盖。这是文件级原子持久化，不是跨所有文件的数据库事务；仍应做独立备份。

## 测试

```sh
cd sub
npm ci
npm test
```

`jsdom` 仅用于开发测试。统一测试入口自动启动临时服务、分配空闲端口并创建独立数据目录，不需要现成服务或个人路径。覆盖服务器权限/ZIP/备份/重启/冲突/故障、编辑保存队列、草稿恢复/切页/手机抽屉/任务创建，以及原有 Markdown、DOM、编辑、属性、锁定/登录流程。服务端 ZIP 互操作测试另需 Python 3 的标准库 `zipfile`。

## 主要 API

| 方法与路径 | 说明 |
| --- | --- |
| GET /api/state | 已授权的工作区概览 |
| GET/POST /api/pages | 列表、新建 |
| GET/PUT/DELETE /api/pages/:id | 读取、带版本校验的保存、回收 |
| POST /api/notebooks/:id/lock・unlock・relock | 设置锁、解锁、重新锁定 |
| GET /api/export/page/:id・/api/export/all | Markdown 交换导出 |
| POST /api/import | multipart Markdown / ZIP 导入 |
| GET /api/backup | 完整备份 |
| POST /api/backup/restore | multipart `file` 恢复至空库 |
| GET /api/reminders | 当前提醒发生时间及 originalReminderAt |
| POST /api/login・/api/logout | 服务器会话 |

## 验证边界

修复回归覆盖 Node.js 本地服务、真实 Chromium 的 360/390/430 像素手机视口与电脑视口。手机视口模拟不等于 Android/iOS 真机验收；Safari、厂商后台限制、大库压力和公网长期运行仍需相应环境验证。
