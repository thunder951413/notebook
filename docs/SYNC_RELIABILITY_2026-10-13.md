# 同步可靠性与自助修复（2026-10-13）

范围：Electron 桌面端与 Android（`notebook_android`）。远端仍是坚果云 WebDAV v4.1 日志格式（`journal/<设备>.jsonl` + `.head.json` + `objects/`），**没有改变线上协议**，新旧客户端可以混用；只改变了客户端在异常情况下的行为。

## 1. 之前会让同步“卡死”的情况

| 场景 | 旧行为 | 现在 |
| --- | --- | --- |
| 两台设备同时改同一篇笔记 | 桌面：整次拉取停在冲突处，自动同步暂停，本机修改也不再上传，直到手动“以本机为准”。Android：该设备之后的所有记录都被挡住。 | 自动处理，同步继续：保留本机版本并作为远端分支的**后继版本**发布；若两边正文不同，另一版本另存为新笔记“原标题（冲突副本 M月d日 HH:mm）”，所有设备都会收到。 |
| 有人清空/删除了坚果云上的同步目录 | 设备序号从 1 重新开始，其他设备因读取位置更大而**永久跳过**新记录；新设备拿不到旧笔记。 | 读取端发现序号回退会从头重读；写入端序号永不回退；本机日志在云端丢失时自动重新上传全部内容（空目录首次连接同理）。 |
| 日志已上传但提交标记（head）上传失败 | 其他设备每次同步都报“日志与提交标记不一致”，直到写入方重新上线。 | 只读取已提交的序号范围并记录警告，不阻断任何设备；写入方下次同步会补发。 |
| Android：某条记录引用的笔记尚未到达 | 整次同步失败并报错（连本机修改也不上传）。 | 该设备的读取位置停在这条记录前等待，其余记录照常应用、本机照常上传；48 小时后仍等不到笔记则跳过并记日志。 |
| 本机读取位置丢失（崩溃、进程被杀） | 可能把自己或别人的旧记录重放成“冲突”。 | 桌面读取位置与数据写在同一个 IndexedDB 事务；Android 同时写入 Room；自己日志的重放永不算冲突；比已接受版本更旧的记录直接跳过。 |
| 坚果云限流（429/503） | 立即失败，等下一次自动同步。 | Android 按 Retry-After 短暂退避重试；两端错误提示改为人话并说明会自动重试。 |

## 2. 冲突策略（两端一致）

版本号语义不变：日志里的 `ver` 是父版本，本机基线 = 已接受的父版本 + 1。

1. 来自本设备日志的记录：本机已有更新基线或有待上传修改时直接跳过。
2. 有待上传修改且远端记录比基线还旧：是祖先，跳过。
3. 真正的并发（同父版本或远端兄弟分支）：
   - 本机基线提升到 `max(本机基线, 待上传父版本, 远端 ver + 1)`，待上传修改改挂在该版本上；
   - 正文（`document`）不同：生成冲突副本笔记（私密笔记的副本仍是私密的）；
   - 页面元数据、标签、步骤等：保留本机；
   - 继续处理后面的记录，不再暂停自动同步。
4. 其他设备随后收到本机发布的后继版本，按正常顺序应用，不会再产生冲突。

旧版本客户端遗留的“冲突”标记会在下次拉取到对应记录时自动清除。

## 3. 用户可见的修复入口

桌面“设置 → 同步与连接 → 同步状态与修复”，Android“设置与同步 → 坚果云 WebDAV → 同步状态与修复”：

- 显示上次成功同步时间、等待上传条数、冲突副本数量。
- **重新读取全部云端记录**：清除读取位置，从头核对所有设备日志（幂等，不删除、不重复）。适用于“别的设备的修改迟迟不出现”。
- **重新上传本机全部内容**：把整个本机库作为当前版本的后继重新排队上传。适用于云端目录被清空、新设备缺笔记。
- 以上操作都可以安全重复执行。仍有问题时导出诊断日志（两端日志都新增了 `conflict-auto-resolved` / `sync.conflict_resolved`、`repository-warning`、`sync.repository_reset`、`sync.republish` 事件）。

## 4. 节奏调整

- 桌面：停止修改 30 秒后同步（原 60 秒），持续编辑最多等 3 分钟（原 5 分钟）；窗口可见时每 10 分钟检查一次云端（原来没有轮询，手机上的修改要等切换窗口才出现）。
- Android：启动/切换前后台时排队的多个同步任务，若 20 秒内刚成功且本机无待上传内容则跳过，减少坚果云请求次数。

## 5. 验证

- 桌面：storage-renderer 59、desktop 58（+10 跳过）、renderer 235 项测试，typecheck 通过。新增：自动解决冲突且不中断拉取、冲突副本内容与同步、相同正文不生成副本、自身重放不算冲突、序号回退重读、写入序号下限、提交标记不一致只读已提交部分、云端缺少本机日志时自动重新上传。
- Android：单元测试 191 项通过。新增/改写：并发编辑自动解决并作为后继发布、另一台新设备无冲突恢复、远端目录清空后序号不回退且旧读取位置的设备能重读、等待父笔记不再导致同步失败、提交标记不一致只读已提交部分、搜索解析与排序、日期分组。
