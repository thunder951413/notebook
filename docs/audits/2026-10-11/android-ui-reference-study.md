# 系统笔记界面与交互实机研究

本次研究以手机上的 ColorOS 系统“笔记”为参考，目标是让 Notebook Android 尽量还原其布局、交互和切换效果，同时沿用已有笔记数据、Markdown 与同步能力。用户已确认本轮只完成学习和计划。核心发现是：这款应用把首页、笔记库、阅读、编辑、选择和工具面板组织成不同状态，同一个悬浮操作区随状态改变，复刻必须同时处理布局、状态和动效。

## 首页与导航

首页背景取样为 `#F0F1F2`，卡片表面为 `#FFFFFF`，主要文字取样为 `#191919`，次要文字常见 `#757575`。橙色用于 AI、选中状态和部分操作反馈，黑色用于主要创建按钮。圆形工具按钮、底部胶囊和浮层带浅色边缘、阴影及不同程度的背景模糊。

顶部右侧是两个分离的圆形按钮：搜索和更多。首页上方的“灵光一刻”包括标识、较大的衬线标题、箭头及灰色说明。标题有单行和多行状态，区域高度随内容变化；列表不能使用固定的首屏起点。上滑后该区域随内容离开，顶部工具按钮仍悬浮在渐变和模糊背景上。

底部同时存在左侧 AI 圆形入口、中间“笔记／笔记库”双标签胶囊和右侧黑色创建按钮。切到笔记库后，创建按钮的图标和用途改为新建笔记库。列表滚动时底部区域维持固定位置，最后一张卡片需要留出安全的滚动空间。

| 布局项 | 当前设备上的测量 | 实现意义 |
| --- | --- | --- |
| 列表外边距 | 48 px，约 16 dp | 窄屏仍保留卡片呼吸空间 |
| 卡片内容水平内边距 | 48 px，约 16 dp | 标题、摘要和时间共用左基线 |
| 普通文字卡片宽度 | 984 px，约 328 dp | 占满可用宽度 |
| 普通卡片高度 | 常见 287 px，约 96 dp | 有附件、不同文字或字体时应自适应 |
| 卡片间距 | 常见 36 px，约 12 dp | 保持分组节奏 |
| 顶部圆形按钮区域 | 120 × 120 px，约 40 × 40 dp | 视觉尺寸与实际点击热区分开定义 |
| 底部独立圆形按钮 | 168 × 168 px，约 56 × 56 dp | AI 和创建入口共享尺寸 |
| 底部双标签胶囊 | 约 172 × 56 dp | 阅读等页面根据按钮数量改变宽度 |

这些尺寸来自控件边界和像素取样。圆角、阴影、模糊强度及字体的实际参数仍需用实现产物对照，不能把截图中的文字框高度直接当作字号。

## 笔记卡片与筛选

普通卡片包含较粗的标题、一行省略摘要、更新时间和右下角更多按钮。带图片的卡片会在右侧展示缩略图，文字可用宽度相应缩小。点击卡片进入阅读；卡片更多提供复制全文、创建副本、移动和删除；长按卡片进入多选。

进入多选后，顶部操作改为取消、已选数量、全选，卡片右侧出现橙色方形选中标记，底部胶囊改为批量操作。本次用两篇临时笔记验证了选择、创建副本、删除和清理，未对原有笔记执行批量修改。

筛选入口同时控制排序和过滤：更新时间、创建时间，内含附件类型，以及已归类／未归类。附件子菜单包括全部、音频、图片、视频、链接、文档。选择当前排序项旁的方向箭头是排序方向入口，其切换后的完整顺序未单独验证。

筛选子菜单是叠层浮窗：父菜单保留并缩小、淡化，子菜单覆盖到前层，选中项右侧打勾。已录到展开和返回过程。应分别处理关闭子菜单、关闭整个筛选浮层和退出页面，不能让一次返回跨越所有层级。

## 笔记库

笔记库采用文件夹封面网格。本设备观察到一行可容纳三个位置；实际只创建了一个临时库，多个封面的重排、跨行拖动和大库数量表现仍需补测。封面下方是名称和笔记数，封面的彩色部分与半透明白色前景形成层次。

空库首页显示插画、标题、说明和黑色“创建笔记库”按钮。创建采用底部面板，包含封面预览、名称输入、12 个颜色选项、取消与保存；空名称时保存禁用。软键盘出现后，面板向上移动并接近全屏。

进入库内后，上方展示大封面、居中名称和数量，下方使用与首页一致的笔记卡片。底部操作变为“问小布／添加笔记”。库内菜单提供选择、编辑笔记库，以及更新时间、创建时间、添加时间排序。

“添加笔记”首先打开来源菜单，可以从已有笔记添加，也可以进入会议、语音想法、键盘文本输入或内容转换入口。已有笔记选择器是接近全屏的面板，带搜索、筛选、复选框和已选数量。

临时笔记从已有列表加入后，库内数量从 0 变为 1；移出后数量回到 0，而笔记仍出现在全部笔记中。移动选择器中的当前库禁用。此证据足以区分移出与删除，但尚未验证同一篇笔记能否同时归属多个库。

删除笔记库的确认区有两个操作：“解散笔记库，保留笔记”和“删除笔记库和笔记”。本次在临时空库上执行了解散。Notebook 的文件夹删除接口不能直接视为完整满足这两个语义，需要在实现阶段核对笔记和子页面的处理。

## 阅读与编辑

阅读页面先展示时间、大标题、标签入口和正文。顶部包含返回、目录、分享、更多；底部只有 AI 和编辑。正文采用整页滚动，顶部和底部有渐变处理。进入编辑后，顶部改为返回、目录、撤销、重做、完成，底部改为“格式／引用／图片／更多”，并随键盘移动到键盘上方。

完成编辑后回到阅读状态；系统返回在观察到的编辑路径中也会先结束编辑。新建时进入编辑并聚焦标题。动作按钮会根据是否有正文光标、是否有撤销记录、当前段落样式等状态改变可用性。

格式面板包含标题、副标题、小标题、正文、注释，以及粗体、斜体、删除线、强调、下划线、列表、缩进、对齐、段落相关设置、字体、字号和颜色。字号菜单观察到 30、24、20、18、16、14、12；文字颜色包括默认、橙、红、蓝、绿、灰。选中当前段落样式时有浅黄色背景。将临时笔记段落改为“小标题”后，其字号显示 18，目录出现该段落对应条目。

格式和添加面板会占据键盘原先所在区域，关闭后可恢复键盘，正文光标仍保留。该过程需要协调焦点、选区、输入法和面板高度，避免切换过程中正文跳动或触发两次布局调整。

添加面板有待办、表格、高亮块、代码块、文件、视频、音频。实际验证包括：插入默认 2 × 2 表格；进入全屏时转到横屏；在全屏内切到竖屏；插入段落待办并勾选后，圆形选框变黄、文字变灰并出现删除线。表格单元格编辑、增删行列、复杂合并及高亮块和代码块内部菜单仍未完整验证。

引用按钮会先向正文插入 `@`，随后展示笔记候选列表。它是一次编辑命令，不是无副作用的选取器。Notebook 已有页面和块引用能力，后续需要把候选选中、取消、撤销和规范 Markdown 写回组织成完整的一次操作。

## 目录 搜索 标签与回收站

目录是带拖动指示、标题和关闭操作的底部面板。本次覆盖无目录状态和有标题状态；当前标题项显示橙色。多级目录和长文定位精度应继续用临时长文验证。

全局搜索从右上圆形按钮展开为顶部胶囊输入框及取消按钮，底部首页导航消失。搜索结果带分组名称和数量，命中处为橙色，正文命中时摘要定位到匹配片段。输入 `11` 找到三项；清空后慢速输入 `987654` 展示无结果状态。快速 ADB 批量输入出现过结果与输入框不一致，不能把这次输入工具影响推断为参考应用的一般搜索规则。

笔记内查找与全局搜索不同：保留正文，上方显示搜索框，下方出现“当前项／总数”和上下项按钮。标签入口则打开底部标签面板，新增标签在面板内进入输入状态。标签实际新增和删除本轮未执行。

“最近删除”显示数量和 30 天保留说明。打开已删除笔记后，顶部仅提供返回、恢复和彻底删除，普通编辑胶囊消失。恢复和彻底删除都有确认；确认恢复后，当前笔记原位回到普通阅读状态。批量模式的底部是恢复和彻底删除。原先已有的一篇回收站笔记保留。

## AI 内容转换与设置

从临时笔记进入 AI 助手时，该笔记作为输入区的上下文卡片出现，可移除或添加。页面还有历史、新建对话、建议问题、检索范围和创作工具入口。检索范围面板区分全部笔记与指定笔记库。本轮观察界面及选择入口，未发送提问，也未验证生成结果、错误重试和流式回复。

内容转换面板包含链接、扫描、图片／拍照、文档、音频及“小布记忆”。链接面板有链接输入、附加需求和生成按钮，并说明平台公开链接限制。扫描、OCR、文件实际导入和链接总结任务未执行。

设置使用灰底白色分组卡片，分为账号与数据、个性化、音频转录及版本信息。快捷记录页面说明长按首页“＋”打开预设入口，可选会议笔记、说想法、写笔记和更多内容转笔记；当前选择为说想法，本轮未更改。离线语言包页面有中文、英语、印尼语、印地语和西班牙语下载入口，本轮未下载。

会议录制、实时转写、录音暂停与完成、实际附件选择、生成中与失败、深色模式、大字体和其它品牌设备不在已验证范围中。这些是实施前补充取证及后续验收项目，不能把“入口已观察”当作“功能已复刻”。

## 数据清理与影响记录

创建了两篇临时笔记，其中一篇为另一篇的副本，以及一个临时笔记库。当前输入法会转换 ADB 英文输入，最终名称与计划的英文名称不同；清理依据实际截图中的名称和选中状态。临时库先移出测试笔记后解散，两篇测试笔记完成删除、单篇恢复验证、再次删除及仅针对这两篇的彻底删除。

最终首页恢复为 7 篇笔记，笔记库恢复为空，回收站仅保留原先已有的一篇笔记。证据分别为 `153-final-reference-home.png`、`148-library-final-empty.png`、`129-samples-cleaned.png`。

学习引用入口时，观察用原笔记曾短暂被插入一个 `@`。随后撤销，通过 UI 层级对照确认可访问正文与进入编辑前一致；但该笔记更新时间更新为 16:23。此对照确认的是正文文本，不能外推为应用全部内部元数据均未改变。后续所有会写入内容的学习动作使用临时样本。
