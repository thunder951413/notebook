# 小容量日志补充验收（2026-09-05）

本次补充基于同日全面修复，覆盖 Electron、Android 和 sub 网页。使用独立测试目录及 API 35 模拟器，未改动生产笔记数据。使用与 adb 提取方式见 [诊断说明](../../DIAGNOSTICS.md)。

## 设计与边界

- Electron 保留最多 4 MiB、Android 与网页服务器各 2 MiB；网页浏览器最多 200 条且不超过 256 KiB。写入队列有容量限制；保存成功采样，重复错误限流或合并。
- 记录版本、会话、操作编号、时间、耗时、状态、计数和受限源码位置。错误记录不包含异常原文、笔记标题/正文、凭据或完整网址。
- 桌面刷新与保存确认使用同一操作编号，网页客户端和服务端使用同一 X-Request-Id；Android 记录同步与草稿恢复结果，支持应用内分享和 Debug adb 提取。
- 日志写入失败与队列溢出不改变业务保存语义；导出在写入队列内生成快照，避免轮转与导出竞争。
- 原始测试输出与截图仅留本机；源码、测试及摘要提交。网页测试已纳入现有 GitHub Actions。
